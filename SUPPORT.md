# Support

For app usage questions, troubleshooting, and general help, start a thread in [GitHub Discussions](https://github.com/jonbrown21/Seafood-Guide-iOS/discussions). Include the app version, iOS version, device model, expected behavior, and screenshots when useful.

Use [GitHub Issues](https://github.com/jonbrown21/Seafood-Guide-iOS/issues) only when you can describe a reproducible defect or a concrete change. Do not post sensitive security details publicly; follow `SECURITY.md` instead.

This community project does not guarantee response or resolution times.
